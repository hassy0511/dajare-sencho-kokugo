# 船・島アートの運用

スタート画面の船と島選択画面の5島は、OpenAI Images 2.0で制作したゲーム用ワールドアートです。承認済みのダジャーレせんちょう立ち絵を画風参照に使い、太い暗色輪郭、丸いデフォルメ、高彩度の配色、シンプルなセル画風陰影を共通ルールにします。

## 管理方法

- `art/source/world/*-source.png`: 生成時の原寸原本。透過処理用のマゼンタ背景を含みます。
- `public/assets/images/world/*.png`: ゲーム配信用の512×512透過PNGです。
- `data/assets/world_images.json`: 用途、配信画像、原本、代替説明を結ぶ正式な画像台帳です。
- `scripts/optimize-world-images.py`: 透過処理後の画像をトリミングし、512×512へ軽量化します。

## 追加・更新時の確認

1. 画像内に文字、ロゴ、ドクロ、武器、人物を入れません。
2. 島は海岸線が一周見え、地形とテーマ別ランドマークだけで見分けられる構図にします。
3. 原寸原本と配信用画像を同時に保存し、画像台帳を更新します。
4. 配信用画像は透過を保ち、1枚150KB未満を目安にします。
5. スマホ比率の実画面で、文字やタップ領域との重なりを確認します。
