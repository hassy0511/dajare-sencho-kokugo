# 03. カリキュラムフレームワーク(学習指導要領準拠)

## 1. 拠り所と方針

- 準拠先: **小学校学習指導要領(平成29年告示)国語** および同解説国語編・系統表(いずれも文部科学省公開資料)。学年別漢字配当表を含む
- **特定の教科書会社に寄せない**。教科書掲載作品・単元名・紙面形式を使わない。読解文は自作オリジナル、昔話はパブリックドメインの自作再話
- 指導要領は内容を**2学年帯**(1-2/3-4/5-6年)で規定する。学年単位で明文配当されているのは主に**漢字**(80/160/200/202/193/191字)と**ローマ字(3年)**・**毛筆(3年〜)**。帯内の学年割りは検定教科書各社の共通傾向に従う(±1学年の揺れは仕様として許容)
- 各ステージは必ず「対応する指導事項」をデータ内 `skillRef` に持つ(例: `1-2知技(1)ウ`)。おうちのひと画面で表示できるようにする

## 3. 5島テンプレートへの割り付け規則

全学年で島の役割を固定する(構造が学年をまたいで自明になり、実装はデータ差し替えで済む):

| 島 | 指導要領対応 | 学年による中身の変化例 |
|---|---|---|
| もじの しま | 知技(1) 文字・表記 | 1年:ひらがな・カタカナ → 3年:ローマ字・送り仮名 → 5年:仮名の由来 |
| かんじの しま | 知技(1) 漢字 | 各学年の配当漢字。3年:音訓・部首 → 4年:漢字辞典。**読み先行・書き(認識系)は漸次** |
| ことばの しま | 知技(1) 語彙・文法・言葉遣い +(3)ことわざ等 | 1年:数え方 → 2年:反対語 → 3年:こそあど → 4年:慣用句 → 5年:敬語 |
| よみときの しま | C読むこと +(3)昔話・古典 | 1年:だれが何を → 3年:要点 → 4年:要約 → 5年:要旨・事実/意見 → 6年:主題 |
| かきかたの しま | B書くこと | 1年:文の組み立て → 3年:段落 → 5年:事実/意見の書き分け → 6年:意見文・推敲 |

- 1島 = 6〜10ステージ。中盤に「かくにんテスト」(幹部ミニ戦)、末尾に「ボス」(まとめテスト)。難度は「絵の補助あり → 補助減 → 文字だけ → 混合」の順に上げる(スキャフォールド原則)
- 1海域 ≈ 35〜45ステージ。海域の最初の島は「もじの しま」とし、その第1ステージが体験版
- 出題は原則「読み・選択・並べ替え」系。漢字の「書き」は第1フェーズでは筆順・画数・部品組立で代替し、なぞり書き判定は第2フェーズ(`docs/06` §trace)

## 4. 2〜6年の海域概要(詳細設計は学年着手時に `04_gradeN_design.md` として追加)

- **2ねんの うみ**: 反対語60・類義語30(`reference/words_kokugo.json` に既存データあり)を ことばのしま で使用。漢字160字のデータ新規作成が主作業
- **3ねんの うみ**: ローマ字(もじのしま)、こそあど・つなぎ言葉・辞書引き(ことばのしま)、要点(よみとき)。俳句の音読は「リズムに合わせたタップ」等の独自形式を検討
- **4ねんの うみ**: 慣用句・故事成語はダジャレ世界観と最高に相性が良い(幹部ヨジロウが間違えて使う→直す、が出題になる)
- **5ねんの うみ**: 敬語(幹部ケイゴロウ)、事実と意見の仕分け(`sortbin`)、古文冒頭の音読・並べ替え
- **6ねんの うみ**: 推敲(幹部オオダコ提督の赤入れを直す)、意見文の構成(`arrange` の集大成)

## 5. コンテンツ制作の権利ルール(全学年共通)

1. 文章はすべてオリジナルで書き下ろす(前作 readings 25本と同方式)
2. 昔話・神話はパブリックドメインの題材(ももたろう・かぐやひめ等)を**自分の言葉で再話**する。特定絵本・教科書の本文を写さない
3. 古文・漢文(5-6年)は原典がパブリックドメイン(竹取物語冒頭等)。訓読・現代語訳も自作する
4. 慣用句・ことわざ・漢字の音訓・画数などの**事実データ**は著作物ではないので自由に使う。ただし特定辞書の説明文をコピーしない
5. フォント・音源は同梱可能ライセンス(OFL / CC0 / 自作)のみ。出典を `CREDITS.md` に記録する
