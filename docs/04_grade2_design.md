# 04. 2ねんの うみ 詳細設計

## 1. 海域の目的

- 海域名: **2ねんの うみ**
- 幹部: **ウラガエル**。何でも反対に言う、あまのじゃくなカエル
- 学習の中心: 2年生配当漢字160字、カタカナで書く語、反対語・類義語、主語・述語、場面と気持ち、順序のある短文
- クリア条件: 公開済み全ステージのクリアだけでなく、2年生の必修項目をすべて取り返して図鑑へ登録する
- ID方針: すべて `g2-` 名前空間で新設し、公開後は変更しない。1年生のID・進捗には触れない

## 2. 物語

ダジャーレせんちょうは、ウラガエルに「2ねんの うみの たからを、ぜんぶ うらがえして かくせ」と命じた。ウラガエルは、反対語を入れ替え、文の主語と述語をひっくり返し、物語の順番まで逆さにしてしまう。正解すると裏返されたカードが表に戻り、漢字や言葉の技が「こくごの たからずかん」に登録される。

ウラガエルの正式立ち絵は、2026-08-23にA案を承認した。挑戦状ではダジャーレせんちょうの次に登場し、反対方向を指さしながら「できたら おうちに かえる! カエルだけに な!」と強がる。

## 4. 最初の縦切り

`g2-moji-gairaigo` を最初の遊べるステージとする。8問の4択で、物の説明から正しいカタカナ語を選ぶ。「最初の文字は何か」を繰り返さず、**言葉の意味と、外国から来た言葉をカタカナで書くという規則**を同時に扱う。

最初の公開単位では、残り40ステージは設計と必修項目の図鑑台帳までを登録し、問題プールの検証が終わったものから順に `planned` を `playable` へ切り替える。未完成問題をランダム生成で水増ししない。
