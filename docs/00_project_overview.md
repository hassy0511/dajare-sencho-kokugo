# 00. プロダクト概要

## プロダクト定義

| 項目 | 内容 |
|---|---|
| 名称(仮) | ダジャレせんちょうと こくごの ぐんとう |
| 何 | 小学生向けの**国語専用**学習ゲーム。海賊「ダジャレかいぞくだん」から宝を取り返す冒険の文脈でドリル学習をゲーム化 |
| 対象学年 | 小1〜小6(実装は小1から順次) |
| 一次ユーザー | 開発者の子ども(iPad で毎日プレイ、実運用しながら育てる)。将来は一般販売 |
| プラットフォーム | iPad Safari(PWA・ホーム画面追加)が本番。PCブラウザでも動作 |
| 配信 | GitHub Pages(自動デプロイ)。オフライン動作必須 |
| 収益モデル(将来) | **学年 = 販売単位**。各学年の最初の1ステージのみ無料体験版。課金は Capacitor でネイティブ化後に App Store IAP(現フェーズはロックUIのみ実装し全学年アンロック運用) |

## 全体構造

```
アプリ = こくごの ぐんとう(6つの「うみ」)
└─ うみ(海域) = 1学年 = 1販売単位          … 最初から全海域に入れる
   └─ しま(島) × 5 = 領域クラスタ           … 海域内の島は最初から全て選択可
      └─ ステージ × 6〜10                    … 島の中だけ順次アンロック
         └─ もんだい × 8〜12(1問1画面)
```

5島テンプレート(全学年共通・島の役割は固定):

| 島 | 学習指導要領上の対応 |
|---|---|
| もじの しま | 〔知識及び技能〕(1) 文字(ひらがな・カタカナ・表記・筆順) |
| かんじの しま | 〔知識及び技能〕(1) 漢字(学年別漢字配当表) |
| ことばの しま | 〔知識及び技能〕(1) 語彙・文法・言葉遣い +(3)言語文化のことば系 |
| よみときの しま | 〔思考力・判断力・表現力等〕C 読むこと +(3)昔話・古典 |
| かきかたの しま | 〔思考力・判断力・表現力等〕B 書くこと(タップ操作に翻訳) |

## 体験の原則(前作から継承)

- **上質な絵本 × 海賊の冒険ボードゲーム**。「目的→挑戦→反応→報酬→次」のループを画面上で保つ
- 子どもを否定しない。不正解は「おしい!」、失敗時は相棒コンパスが励ます(敵は出さない)
- どの学年(海域)から始めても違和感がない。海域ごとに物語が自己完結し、学年間の依存はない
- 見た目・アクションの品質を妥協しない(前作の反省)。トゥイーン・パーティクル等の「ゲームのジュース」を標準装備するため Phaser を採用

## 前作(bouken-drill)から引き継ぐもの / 引き継がないもの

| 引き継ぐ | 引き継がない |
|---|---|
| 世界観(ダジャーレ船長・コンパス)、ダジャレ品質4基準 | 算数コンテンツ全て |
| 2層分離思想(ロジック/データ)、島フレームワーク | 単一HTML・ライブラリ禁止・CSSのみアニメの縛り |
| セルシェーディングSVGのアート方針と既存国語SVG資産 | 旧エンジン実装(DOM直操作)そのもの |
| 国語データ(漢字80字・カタカナ60・助数詞32・読解25 ほか) | 絵文字アイコン、jsdom による盲目検証 |
