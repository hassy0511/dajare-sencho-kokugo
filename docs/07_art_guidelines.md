# 07. アートガイドライン(SVG / ラスター)

前作で確立した品質基準を継承する。**初期バージョンが「絵文字+ベタ塗りでしょぼい」と却下された経緯があり、この基準を下げない。**

## 基本作法(全SVG必須)

- **すべての図形に輪郭線**: `stroke="#3D3323"`(Ink Line)、`stroke-width="1.5〜2.5"`、`stroke-linejoin="round"`
- **単色ベタ塗り禁止**: 1つの立体につき最低2階調(明部・暗部)を別パスで塗り分ける(セルシェーディング)
- **グラデーション不使用**
- **光源は右上45度で統一**
- 石・岩は完全な長方形にしない(四隅を数px歪ませる)
- 絵文字をアイコン代わりに使わない
- 見本: `reference/svg/` 一式(前作の完成品)。新規作画は必ず既存見本とトーンを並べて確認する

## キャンバス規格

| 用途 | viewBox | 備考 |
|---|---|---|
| キャラクター(船長・コンパス・幹部) | `0 0 120 120` | 表情差分を含む |
| シーン(マップノード絵) | `0 0 120 120` | 「光る要素」を1つ持たせる(挑戦中グロー演出のターゲット。旧 `bd-arch` クラス相当は Phaser 側で扱うため、**光る要素の group id を `glow` に統一**する) |
| 島カード(しまえらび) | `0 0 160 112` | 見本: `island_card_reference.svg` |
| 宝物 | `0 0 100 80` | 2状態演出をしたい場合は `tr-a`(初期)/`tr-b`(変化後)の2グループ |
| うみカード(うみえらび・新規) | `0 0 160 112` | 学年数字を大きく+海域の景色。6学年で並べて識別できる配色に |

## キャラクター仕様

- キャラクターの正式な共通画風と再生成プロンプトは `art/prompts/character-mascot-style.md` を唯一の基準とする
- 太いダークカラーの輪郭、丸く誇張した形、左右非対称の目と眉、少し歪んだ大きな笑顔を使い、「アホっぽくて憎めない」子ども向けマスコットにする
- 鮮やかな高彩度色、整理されたデジタルの色面、単純なセル画風の影と柔らかなハイライトを使う。繊細で上品な絵本風、写実、油絵や鉛筆の強い質感にはしない
- 全身を中央配置し、薄いクリーム色またはオフホワイトの無地背景と足元の薄い楕円影だけを使う
- 正式キャラクターにラスター画像を使う場合は、表情ごとに別ファイルを用意し、Phaserでは表情別テクスチャの差し替えで切り替える
- ラスターの原寸原本は `art/source/characters/`、512×512の配信用PNGは `public/assets/images/characters/`、対応関係は `data/assets/character_images.json` で管理する
- SVGキャラクターを追加する場合は従来どおり `face-normal` / `face-angry` / `face-oops` のグループを持たせ、ビルド時に表情別テクスチャへ変換する
- 新キャラ(幹部)は「怖くない悪役」: 丸いシルエット・丸い目。ドクロ・武器・とがった歯は描かない
- ダジャーレせんちょうの正式デザインは2026-07-23承認。大きな紺帽、赤いコート、緑のヒゲ、丸い体型、得意げだがアホっぽい表情を識別要素とする

### スミゾー(1年幹部)の作画指示
- 正式デザインは2026-07-23承認。スミイカのずんぐり丸い胴+短い足(触腕)、赤い海賊バンダナ、片方が上がった眉と少し間の抜けた笑顔を識別要素とする
- 片手(触腕)に大きな筆。体のどこかに墨だれ模様
- 明部・暗部: 胴は薄グレー系2階調+墨の黒はアクセントに限定(画面が重くならないよう)
- 表情3種: normal(ドヤ)/angry(かくにんテスト・ボス時)/oops(負け)

## 動きの規格(Phaser 側)

- アイドル: キャラは常時ゆっくり上下(±3px, 2s, Sine.inOut)。完全静止させない
- 登場: スケール 0.8→1.0 + Back.easeOut(250ms)
- 表情切替: 80ms のクロスフェード
- パーティクル色はテーマ配色から取り、1画面同時 100 粒以下(iPad 60fps 維持)

## 問題用ラスター画像ライブラリ

問題中の挿絵は、コードで直接描画せず、OpenAI Images 2.0で生成したラスター画像を利用する。実行時の外部通信は禁止し、最適化済み画像をすべてリポジトリへ同梱する。

この節の絵本風画風は問題用の絵カード専用であり、キャラクターには適用しない。キャラクターには `art/prompts/character-mascot-style.md` のコミック調マスコット画風を適用する。

- 実ファイル: `public/assets/images/words/<key>.png`（512×512 PNG）
- 管理マニフェスト: `data/g1/assets/word_images.json`
- Phaserテクスチャキー: `word-image:<key>`
- マニフェストには `key`、対応する `word`、配信パス、読み上げ用の `alt`、再生成用の `subjectPrompt`、共通画風プロンプトを保存する
- 問題プールの `visual` はマニフェストの `key` を参照し、テストで単語との1対1対応と実ファイルの存在を検証する
- 統一画風は、絵本風のガッシュ+色鉛筆、丸い形、濃い茶色の手描き輪郭、2階調の陰影、暖かなアイボリー背景とする
- 画像内には文字・ロゴ・透かし・不要な小物を入れず、220px表示でも対象を一意に判断できる構図にする
- 新しい絵を追加するときは、既存の基準画像を画風参照にし、マニフェストと問題プールを同じPRで更新する
