## 実装順の理由

- PR-2 で「エンジンの心臓部(クイズ体験)」を最速で見せて品質判断を仰ぐ(前作の「しょぼい」リスクを最初に潰す)
- 島の完成は かんじのしま を先行(データが完成済みで、コンテンツ制作と切り離してエンジン品質を検証できる)。リリース時の島の並びは もじ→かんじ→ことば→よみとき→かきかた
- qtype は使う島の PR で追加(一括実装しない)
