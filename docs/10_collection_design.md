# 10. こくごの たからずかん設計

> 状態: 2026-08-22 承認済み・実装中。

## 目的

初回攻略では問題候補を無作為に省略せず、未回収の学習項目を優先する。正解するとスミゾーの墨がはがれ、「こくごの たからずかん」へ登録される。必修項目をすべて取り戻すことを島・海域の完全クリア条件とする。

## 図鑑の5分類

| 島 | 取り戻すもの | 1年生の必修項目 |
|---|---|---|
| もじの しま | もじの かけら | ひらがな46字、カタカナ46字、かなの4つのわざ |
| かんじの しま | かんじの かけら | 1年配当漢字80字、漢字の3つのわざ |
| ことばの しま | ことばの カギ | なかま、数え方、丁寧語、文の柱、様子、しりとり |
| よみときの しま | おはなしの しるし | 人物、事柄・場所、順序、重要語、昔話、長文 |
| かきかたの しま | ぶんの どうぐ | 語順、助詞、句読点、経験順、読み返し |

## 必修回収ルール

- 未回収項目を多く含む問題を優先し、選択肢の位置だけをランダム化する。
- 文字問題は1文字だけを反復せず、絵や音から言葉を選び、正解した言葉に含まれる文字をまとめて回収する。
- 漢字は1字単位、文法・読解・作文は概念カード単位で回収する。
- 不正解項目は未回収のまま次回以降へ回し、正解するまで必修列から外さない。
- ステージは正答率60%以上かつ、そのステージの必修項目100%回収でクリアする。
- 確認テストとボスは回収済み項目の定着確認とし、新規項目を増やさない。
- 全回収後の復習では、問題順もランダムにしてよい。

## セーブ互換

セーブをv2へ移行し、項目ごとの回収・正解・迷った回数を保存する。v1でクリア済みのステージに属する項目は回収済みとして移行し、既存利用者の進捗を減らさない。
