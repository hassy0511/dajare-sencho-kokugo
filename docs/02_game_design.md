# 02. ゲームデザイン(世界観・キャラ・ダジャレ品質基準)

## 1. 物語の骨格

- 黒幕は **ダジャーレせんちょう**(ダジャレかいぞくだんの船長)。「こくごの ぐんとう」から、学年で身に付けるすべての文字・漢字・言葉と文法の力を「こくごの たから」として盗み、**海域(=学年)ごとに幹部(子分)1体**を置いて居座らせた
- プレイヤーは相棒の **コンパス**(方位磁針の妖精。初回起動時に子どもが命名)と一緒に島の問題を解く。正解すると幹部の墨がはがれて対象の文字・文法を取り返し、その場で「こくごの たからずかん」へ登録する
- **海域ごとに物語が自己完結**する: 海域に初めて入ると船長の「ちょうせんじょう」→ 5島で必修の宝を一つずつ回収 → 全ステージクリアかつ図鑑コンプリートで幹部が改心し、海に言葉の力が戻る → 船長は「また ダジャレしに くるぜ〜!」と逃げるだけ。**学年間の続き物にしない**(どの学年から始めても成立)
- 優しい結末の原則: 敵を退治・排除しない。幹部は改心して友達側になる。怖い要素(ドクロ・武器・とがった歯)は描かない

## 2. キャラクター

### ダジャーレせんちょう(全海域共通の黒幕)
- 自称「うみで いちばん おしゃれな かいぞく」。自信満々・見栄っ張り・実は全然悪くなれない小物。負けるたびダジャレで強がる
- 口癖: **「〜だけに な! がっはっは!」**(毎回この型で締める繰り返しギャグ)
- 登場場面: 海域初回の挑戦状 / 海域全クリアの締め / ずかんの宝物コメント(1行ダジャレ)。**ステージの不正解時には絶対に出さない**
- 正式normal画像: `public/assets/images/characters/dajare-sencho-normal.png`。原本・承認日はキャラクター画像台帳で管理
- 旧SVG: `reference/svg/captain_dajare.svg`(ファイル名は移植元のまま・参照専用)

### コンパス(相棒・全海域共通)
- 子どもが名前を付ける(`state.buddyName`)。セリフでは【なまえ】で参照
- 役割: ナビゲーション+励まし+**船長のダジャレへのツッコミ役**(「さむ〜い! うみが こおっちゃうよ!」「でた〜、『だけにな』だ〜」、たまに「いまのは ちょっと おもしろかったかも…」)
- SVG: `reference/svg/compass_buddy.svg`(表情4種: normal/happy/oops/super)

### 海域幹部(学年ごとに1体・新規デザイン)
各海域の5島すべてに居座り、島ごとにセリフを変える。定義は「SVG 1体(表情3種)+性格+口ぐせダジャレ」の3点セット。

## 3. ダジャレ品質基準(全セリフ必須・前作 concept_v6 §2 を継承)

**セリフのダジャレは以下4基準をすべて満たすこと。校正時は一覧表で機械的に確認する。**

| # | 基準 | 説明 |
|---|---|---|
| 1 | 音の重なりが明確 | 同音または準同音が**最低2モーラ**重なる(例: こうかい/こうかい)。「なんとなく似ている」はNG |
| 2 | 両方の意味が子どもに分かる | 掛けた2語とも対象学年の子が知っている語であること |
| 3 | ひらがなで読める | 分かち書き・ひらがな中心。カタカナは既習語のみ |
| 4 | 文脈に乗っている | その島・宝物・場面に関係する語で掛ける |

- NG例: 「サメだけに シャレに ならんぜ」(音が重なっていない) / 「わたさん! わたしだけにな!」(意味の二重性がない)
- OK例: 「こうかい するなよ? かいぞくだけに、**こうかい(航海)** なら まいにち してるけどな!」 / 「もんだいが **とけた**? **とけい**だけに な!」
- 下品要素ゼロ(うんこ・おしり系語彙は使わない)。煽りは「よめないだろうけどな!」程度まで

## 4. ゲームループ(目的→挑戦→反応→報酬→次)

| 段階 | 実装 |
|---|---|
| 目的 | 海域の挑戦状/海域・島・ステージ画面で「盗まれた文字・文法を全部取り返し、図鑑を完成させる」が常に見える |
| 挑戦 | 1問1画面のクイズ(出題タイプは `docs/06`)。ドット進捗表示。同一クイズ内の実体重複禁止(gen の `key` で担保) |
| 反応 | 正解: 約1秒のポジティブ演出(パーティクル+SE)。初回正解した必修項目は墨がはがれ、「ずかんに とうろく!」を表示する。不正解: 「おしい!」+正解提示(約2秒)。**テンポ最優先、スキップ可能** |
| 報酬 | 初回正解ごとに対応する文字・漢字・概念カードを即時回収し図鑑へ登録。結果画面で今回の登録内容とステージの回収数を確認できる。★評価は正答率による補助評価とする |
| 次 | 正答率60%以上かつステージ必修項目100%回収で次ステージへ。未回収があれば同ステージを続ける。全41ステージかつ全196項目回収で海域エンディング(改心シーン) |

- 合格ライン: 正答率60%以上かつ、そのステージの必修項目100%回収でクリア。**不合格時は幹部・船長を出さず**、コンパスが励まして再挑戦を促す
- かくにんテスト(`test`)ステージ: その島の全タイプ混合+幹部が登場して煽る。ボス(`boss`)ステージ: 島の総まとめ+クリアで特別演出
- あそび回: 各島に1つまで「べんきょう感の薄い」アクション寄りステージ(dig・しりとり等)。**参考書の「めいろ・点つなぎ」形式はそのまま使わず、必ず独自形式にする**(模倣回避。前作方針の継承)

## 5. 演出の最低ライン(「しょぼい」の再発防止)

Phaser 標準機能で以下を必ず入れる。CSSアニメ時代の静的な画面に戻さない:

- 全ボタン: press時スケール+リリースでバウンス(Back.easeOut)
- 正解: 選択肢が弾む+星パーティクル放出+コンボ表示(連続正解でカウント+ちょっと派手に)。初回回収時は墨がはがれてカードが現れ、「ずかんに とうろく!」までを一続きで見せる
- 不正解: カードシェイク+正解が光る
- 画面遷移: フェード+スライドのシーントランジション(300ms以内)
- マップ: 現在地マーカーの浮遊ループ、クリア済みノードのきらめき、幹部キャラのアイドル動作(ゆっくり上下)
- ボス戦: 出題ごとに幹部のバリアが1枚ずつ割れる進捗演出、クリアで画面シェイク+花火
- 効果音: タップ/正解/不正解/クリア/宝物/ページ送りの6種以上。BGM はマップ/クイズ/ボスの3ループから
- 設定に「アニメひかえめ」トグル(OS の reduced-motion も尊重)
